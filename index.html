About FloraLens

Learning plants through AI

FloraLens is an educational plant-recognition project. Its machine-learning model is trained using Google Teachable Machine to recognize selected plant categories. The website provides a simple interface for demonstrating how image classification can be applied to plant recognition.

⚠️ Important

FloraLens is an educational AI demonstration. Do not consume, prepare, or use a plant as medicine based only on this AI prediction. Always verify plant identification using reliable expert sources.
